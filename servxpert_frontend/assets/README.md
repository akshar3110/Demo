# Assets Directory

This directory contains the assets required for the ServXpert registration app.

## Required Images

### `images/`
- `serve_xpert_x_logo.png` - Company logo (50x50 pixels)
- `serve_xpert_name_logo.png` - Company name logo (150px width)

### `icons/`
- `india_flag.png` - India flag icon for phone number field (24x24 pixels)

## Required Fonts

### `fonts/` (Create this directory in the root)
- `Fredoka-Regular.ttf` - Main font for headings and buttons
- `Fredoka-Bold.ttf` - Bold variant for emphasis
- `SansSerif-Regular.ttf` - Body text font
- `SansSerif-Bold.ttf` - Bold variant for body text

## Notes

1. Make sure all image files are in PNG format for best compatibility
2. Font files should be in TTF format
3. Maintain aspect ratios for logos to ensure proper display
4. Consider providing @2x and @3x variants for different screen densities

## Asset Optimization

- Compress images to reduce app size
- Use vector graphics (SVG) where possible for scalability
- Test assets on different screen sizes and densities
